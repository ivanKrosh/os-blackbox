# Чорна скринька

*Операційні системи · змістовий модуль 1 · індивідуальне завдання*

Програма `blackbox` для індивідуального завдання «Інтелект-карта „Чорна скринька“». Повний текст завдання, маршрут дослідження і критерії оцінювання — у Google Classroom курсу.

## Як отримати і запустити

У терміналі віртуальної машини Ubuntu:

```bash
wget https://github.com/ivanKrosh/os-blackbox/releases/latest/download/blackbox
chmod +x blackbox
./blackbox 372-07
```

Замість `372-07` — **ваш код**: номер групи і ваш номер у списку групи в журналі, двома цифрами (`331-05`, `371-12`, `372-07`).

## Що треба знати

- Скринька працює 20 хвилин, зупинити достроково — `Ctrl+C`. Перезапускати можна скільки завгодно.
- Досліджуйте її **в другому вікні термінала**, поки вона працює.
- Запускайте лише свій код: за чужим кодом скринька поводиться інакше, і карта не збіжеться з ключем.
- Програма зібрана для 64-розрядних процесорів x86-64 (звичайні ПК і ноутбуки з Intel або AMD). Якщо ваша ВМ працює на Mac із процесором Apple M — повідомте викладача.
- Якщо бракує команд для дослідження: `sudo apt install strace psmisc`.
